# 基础短课衔接与练习修正

日期：2026-10-25。审查基线：线上 v115，源码提交 `1eeffcda355fdb04c3a7d78a8bbe51ef9edcc8de`。

## 发现与原因

1. 拆课时，父课程的例题、起步代码只分配给第一门短课。张量形状课因而提前讲矩阵乘法和索引，后面的索引、布局短课又缺少独立的起步算例。零基础讲解按旧课程 ID 查找，也没有覆盖新短课。
2. 三关练习使用位置编号保存答案。旧的一道章末题位于位置 0，新增概念题也占位置 0，旧答案可能显示在另一题上。小节题保存的数字索引键与页面读取的稳定小节 ID 键也不一致。
3. 目录中的“本章综合练习”没有加入页内滚动分支，点击后可能离开当前课程。损失阅读地图仍在拆分前的单门课程里查找小节，缺失时回退到损失起点课。
4. 布局课里单独写“步幅 / stride”会匹配空间步幅；普通动词“微调参数”会匹配迁移学习中的 fine-tuning。多标签题的“标签彼此独立”则容易被误解为现实事件统计独立。

## 已实施

- 为前 12 门深度学习短课分别配置入门说明、符号解释、具体算例、三步演示和最小代码：AI 起点、层与学习、四门张量课、神经元、激活、输出、任务与标签、概率、交叉熵。
- 形状课只以轴数、各轴长度和元素总数为主线；索引、运算、布局在各自课程中展开。reshape 与转置用同一张 `[[1,2,3],[4,5,6]]` 数字表比较，明确相同形状可以对应不同元素位置。
- 神经元互动保留输入、权重、偏置滑杆，把二分类概率转换收进明确的选学折叠项；原始神经元输出不一概称为分类 logit。
- 分类主线沿用“猫、狗、兔”和 logits `[2,1,0.1]`，从标签表示、概率，到真实类概率和约 `2.317` 的单样本交叉熵。代码注明直接将 logits 交给 `CrossEntropyLoss`，展示概率只用于对照手算。
- 37 门课的三关题目按题干、选项和正确项生成稳定标识；选项位置作确定性轮换，避免正确项过度集中于 A。旧位置答案不再套用到新题，旧记录没有删除。
- 小节题统一使用页面生成的答案键，兼容读取旧数字键。点击后同步更新视觉状态与 `aria-pressed`。
- “解释与计算”替换关卡标题里的普通“推理”，避免误触模型 inference 词条。张量语境使用完整的“张量内存步幅”；`Tensor.stride`、`stride()`、`.stride()` 指向内存步幅词条。卷积 `stride=` 继续使用卷积步幅解释。
- 损失阅读地图直接链接到现有短课；章末练习目录使用页内滚动。原有课程 ID、正文小节、笔记和完成标记继续沿用。

## 内容依据

- [PyTorch 张量入门](https://docs.pytorch.org/tutorials/beginner/basics/tensorqs_tutorial.html)：张量表示与基础操作。
- [torch.matmul](https://docs.pytorch.org/docs/stable/generated/torch.matmul.html)：向量和矩阵输入的运算约定。
- [torch.transpose](https://docs.pytorch.org/docs/stable/generated/torch.transpose.html)：交换轴与普通 strided 张量共享存储。
- [BCEWithLogitsLoss](https://docs.pytorch.org/docs/stable/generated/torch.nn.BCEWithLogitsLoss.html)：内部组合 Sigmoid 与二元交叉熵，输入为 logits。
- [CrossEntropyLoss](https://docs.pytorch.org/docs/stable/generated/torch.nn.CrossEntropyLoss.html)：原始 logits、类别索引及归约约定。
