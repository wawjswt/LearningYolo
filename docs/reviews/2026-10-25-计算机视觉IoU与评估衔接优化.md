# IoU、检测匹配与AP的学习衔接

基线：v119，源码提交 `45ec01a48516aa1eea65c2907d1c79befd62ede0`。

## 问题与范围

原课程分别给出了IoU、TP/FP/FN与AP的固定算例，但缺少让学习者从几何位置追踪到匹配和计数的操作。指标课中p4落在背景，AP课中p4却命中第三个真实目标，这个变化没有交代清楚。

本轮修改IoU计算、检测匹配与PR/AP三门课。保留已有课程、小节、笔记与进度键，复用数值计算台、KaTeX和代码复制组件。

## 已实施

- IoU计算台固定A=[0,0,10,10]，可水平、竖直移动同样大小的B框；同步画框与交集，逐项显示交集宽高、面积、并集和比值，并对照左上角/中心两种xywh格式。
- 同步生成无需第三方库的Python代码；矩形采用连续坐标，宽高不加1，限定正面积框。
- 检测匹配台固定真实车A/B/C及四条降序预测。可查看某条预测，调整p3位置、分数门槛和评估IoU门槛，并把p4从背景移到C。
- 按降序分数做单类别一对一教学匹配；逐条列出IoU、TP/FP或未保留的原因，以及累计计数。重复预测不会再次占用同一真实框。
- 显示TP/FP/FN及有数学排版的P/R分式。无预测时精确率未定义，召回为0；不把零分母默认为满分。
- AP课明确先把上一课p4移到C，保持既有四条预测的TP、FP、TP、TP算例；可以移回背景作对照。
- 新增PR点、当前工作点、精确率包络矩形及逐段面积表。分别显示所有召回增量规则与101点采样的结果，不把一个门槛下的P/R当成AP。
- 分数滑杆选择完整排序中的工作点，AP使用本例全部四条排序；说明真实评估若预先硬删候选会改变排序。固定IoU单类演示不冒充完整COCO评估。
- 明确本台不做NMS，保留重复框用于学习匹配；评估IoU门槛与NMS预测间IoU门槛分别解释。

## 核对结果与边界

- 默认IoU=50/150=1/3；完全重合为1，边缘接触与分离为0。检查包含、对称性和非法退化矩形。
- 默认检测例TP=2、FP=2、FN=1，P=0.5、R=2/3。重复p2的最高IoU为0.875，仍记FP。
- p3偏移10时与B的IoU恰为0.5；门槛0.5可匹配，门槛0.75不可匹配。
- p4命中C时，AP=5/6≈0.8333，101点平均≈0.8342；移回背景后，全召回增量AP=5/9≈0.5556，101点平均≈0.5545。
- 29项检查通过，包括新数值规则、阈值边界、AP口径、零预测和既有课程回归。IoU的四组Python例子实际执行，结果与浏览器算术一致。
- 桌面浏览器实际操作框位移、分数门槛、IoU门槛、修正p4和PR图；控制台无错误。手机视口未在本轮实际验证。
- 这些图解为固定教学数据的算术演示，未运行检测模型；匹配不含ignore/crowd、跨图排序、面积分组和maxDets等完整协议规则。
- 最终发布版本与提交以Sites返回记录及任务回复为准。
