下表列出24课的第一批处理与后续重点；本批集中整机、结构、检测头，不声称已完成所有课程的逐段复审。

| `detection-intro` | 本批保留既有内容。 | 保留道路例子；将类别、框、分数和对象条数对应到完整输出记录；再接两类贯穿任务 |

| `yolo-evolution` | 本批保留既有内容。 | 用“当时的问题—主要改法—本课使用哪一项”组织历史；固定本站版本说明，不堆版本名称 |

| `yolo-repository` | 本批保留既有内容。 | 围绕“准备数据、建网络、训练、看结果、改输出头”五个问题找文件；解释文件名与函数职责 |
| `yolo-data` | 标签互动增加贯穿算例预设。 | 先保留简单标签例子，再接贯穿算例；说明磁盘标签与变换后的内存目标；按来源划分数据 |
| `yolo-config` | 逐层浏览器增加完整账本和矩形输入。 | 先解释四项结构，再把一行实际配置展开成模块；指出 from 保存/取用哪些层；深宽缩放后再谈模型大小 |
| `yolo-backbone` | 方图主线与默认交互统一。 | 默认方图；逐步交代 B/C/H/W、卷积步幅、通道来源；解释为什么保留层 4、6 的特征 |
| `yolo-c3` | 合并入口重复定义。 | 合并重复定义；先走 8 通道小例子，再对应实际层；强调两路均读取完整输入，Concat 与内部残差不同 |
| `yolo-sppf` | 合并入口重复定义。 | 将汇总邻域的动机、小表池化、串联窗口范围、真实通道四件事依次讲完 |
| `yolo-neck` | 移除重复定义，保留来源路径图。 | 删除重复定义；先讲单次上采样/拼接/卷积，再走四条完整路径；解释高层、低层与图上方向 |
| `yolo-head` | 统一两类字段及换轴主线，按用途折叠改造内容。 | 先两类 7 字段→21 通道→换轴→三尺度候选→训练/推理返回；项目改类与结构改造分组阅读 |
| `anchors` | 本批保留既有内容。 | 把参考宽高、预测框、真实框分开画；先说明为什么需要宽高参考，再讲匹配范围、统计和自动调整 |
| `yolo-assignment` | 本批保留既有内容。 | 接同一标签；先算像素→网格→匹配→中心格→邻格→索引；一次把一条路径算完 |
| `yolo-loss` | 本批保留既有内容。 | 先列“谁被监督、目标是什么”，逐项代入公式；再处理负位置、跨尺度、gain 和 batch 缩放 |
| `train-yolo` | 本批保留既有内容。 | 文件→一轮检查→一个 batch→一次更新→验证保存；术语在步骤中解释；示例日志逐列读 |
| `yolo-checkpoints` | 本批保留既有内容。 | 用“首次初始化、换任务微调、意外中断恢复”三个场景区分；将输出头不兼容接到参数加载示例 |
| `yolo-augment` | 本批保留既有内容。 | 一次讲清一种变换如何同时改图与框；再比较尺寸、batch 和实验预算 |
| `yolo-evaluation` | 本批保留既有内容。 | 先用固定少量框匹配并计 TP/FP/FN，再算 P/R，再扫分数门槛、AP/mAP、fitness；实现差异放选读 |
| `inference` | 本批保留既有内容。 | 将原始字段、解码坐标、组合分数、NMS、原图还原组织为连续过程；新增贯穿预设，局部旧例单独标明 |
| `yolo-export` | 本批保留既有内容。 | 按“谁读取文件、输入是什么、返回什么、外部还做什么”解释导出；先复核输入和原始输出，再谈最终框 |
| `yolo-trace` | 本批保留既有内容。 | 保留公交车实图；开头列出与两类案例的差异，分基础通读和源码复查；避免重复灌入整套训练术语 |
| `debugging` | 本批保留既有内容。 | 按可观察现象→最早异常环节→证据→一个改动→复查结果组织；每项给能实际找到的文件/数值 |

## 第二批实现记录：标签贯穿训练与推理

日期：2026-10-27。沿用第一批的单张 1000×500 烟雾/火焰图和同一个火焰框，不把手算预测写成模型实测。

### 讲解与交互改动

- **Anchor 与目标分配：** 从同一框的 640×640 letterbox 结果继续换成 P3/P4/P5 网格单位，逐项展示 9 组参考宽高比。5 组通过 `r < 4`（P3 三组、P4 两组、P5 零组）；中心小数为 0.4、0.6，每组各得到中心格及一条水平、一条垂直邻格索引，共 15 条。说明这只是被分配的训练位置，不是 15 个已检测物体；半格与等于门槛的严格比较单独标出。
- **三项损失：** 逐项标明监督位置、训练目标与计算值。假设一个匹配位置预测框完全重合、物体性分数 0.9、类别分数 `[0.2,0.8]`，则 box 为 `1−CIoU=0`、物体性 BCE 为 `−ln(0.9)≈0.10536`、两类平均 BCE 约 `0.22314`；局部未加权合计约 `0.32850`，明确不等于完整 batch 总损失。补充多尺度归约、gain、balance、batch 缩放及可选平滑/Focal 的边界。
- **训练与权重：** 增补数据目录和 YAML 字段、一轮排错命令及结果目录示例；用 `loss=(w−3)^2` 手算 `w=1`、梯度 `−4`、学习率 `0.1` 后得到 `w=1.4`，并提供对应 PyTorch 代码。说明梯度累积下一个 batch 不一定触发参数更新；按首次初始化、换任务微调、同一实验恢复区分 checkpoint。
- **增强、验证与导出：** 用水平翻转算出中心 x 从 530/0.53 变为 470/0.47，强调图片和标签同步变化。明确分数门槛、NMS IoU、验证 IoU 比较对象不同；补验证匹配到 AP 的步骤及同一输入的导出对照流程。
- **推理与排错：** 贯穿算例的理想候选 `[339.2,300.8,32,16]` 与分数 `0.9×0.8=0.72` 经去补边、除缩放后回到原图 `[530,220,50,25]`。NMS 的 A 框沿用该画布坐标，另三框明确为人为构造；排错按框偏移、类别错误、漏检、无框列出优先检查的证据。
