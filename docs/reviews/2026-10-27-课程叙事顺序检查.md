# 课程叙事顺序检查记录

日期：2026-10-27

本轮以实际组合后的 96 门课程为对象，先检查课程标题与小节次序，判断基础概念、计算过程、实践与排错是否出现明显倒序。随后逐段检查并修改下列五门课；本记录不声称已逐段审完全部 96 门课，也不能仅凭标题判断其他课程正文没有跳跃。

| 课程 | 原来的断点 | 本轮阅读顺序 |
| --- | --- | --- |
| 张量 3 | 先进入 reshape、cat 等速查，再讲计算与形状 | 先通过矩阵乘法和广播理解运算及形状，再查形状操作 |
| 优化器 2 | 还没讲动量和 Adam，就先讨论如何比较优化器 | 先理解 batch 与梯度，再讲动量、Adam，最后安排对照实验 |
| Anchor | 匹配之后直接进入修改建议，预测框和解码的解释留在后面 | 从参考尺寸开始，区分参考与预测，再算匹配和解码，最后讨论数据与 AutoAnchor |
| YOLO 训练 | 先看日志、扩大实验，最后才解释一批数据怎样更新 | 先读命令，再走完一次训练与一轮验证，然后读日志，最后安排小样本检查 |
| 推理与后处理 | 先做 NMS、排错，之后才解释原始数怎样变成框 | 先概览流程，再计算解码与坐标，解释分数和参考框，之后讲筛选、NMS 与排错 |

每节之间增加了指向具体问题的衔接句。章节对象、稳定 ID、旧锚点、图解和练习仍由原小节携带；图解使用原来的绑定位置，不随新排序误配。标题中的序号按新的阅读顺序更新。

后续逐段检查应重点对照：一段讲述是否在中途切换案例、公式的符号是否在使用前解释、互动图解与邻近正文是否使用同一组数，以及课末练习是否能用前文解释作答。尤其需要继续人工逐课核对课程主线和前置知识；章节标题清晰并不代表正文已经完整。
