# 复合术语提示匹配全站审查与修正计划

> **实施状态：** 实现、定向回归与 26 门课程浏览器核对均已完成。用户已选择直接在当前 `main` 分支修改，遵循其要求未使用子代理。发布尚待用户授权 Sites 发布流程所必需的 Git 源分支提交与推送；该步骤超出本计划“不擅自提交或推送 Git”的约束。

**Goal:** 全面修正全站术语提示把一个有专门含义的复合词拆成普通子词解释的问题，同时保留普通子词单独出现时的解释能力。

**Architecture:** 继续使用 `dist/textbook-glossary.js` 作为唯一术语词典与匹配入口。为经审定的复合术语建立明确的原子词组/包含关系，让正文、交互控件、行内代码和术语解释卡使用相同的匹配优先级；对中文文本按完整术语处理，不把英文单词边界规则当作中文分词规则。需要兼顾跨相邻行内节点的术语识别，并避开链接、按钮、代码、数学公式及不同段落等不可跨越区域。

**Tech Stack:** 原生 JavaScript、当前静态 HTML/DOM 结构、现有术语解释组件、Node.js 内置断言（若当前验证脚手架不适用，则新增仅供本功能的定向校验脚本）。不引入运行时依赖。

**Spec:** 用户于 2026-10-21 指出 BatchNorm 小节中的“协变量”是完整术语，不应显示成普通“变量”的解释；本计划将同一规则扩展到全站课程、互动图解、控件、题目和术语卡。用户已确认现在实施计划，并明确选择直接修改当前 `main` 分支；验收通过后按计划更新并发布网站。

## 全站审查记录

### 检查范围

- 检查 `dist/index.html` 中的脚本加载关系：42 个本地脚本引用，去重后 41 个本地 JavaScript 文件；同时检查了 `dist/` 下的 JavaScript、HTML 与 Markdown 字面内容。
- 检查全站术语注册表 `dist/textbook-glossary.js`：静态解析到 300 个词条；未发现重复词条 ID，也未发现被不同词条重复占用的完全相同别名。
- 按 26 门课程的当前内容模块和共享词典检查匹配器。页面内容会由基础数据、后续课程扩展和交互组件共同组成，因此词典之外还要检查最终渲染的文本节点和交互控件。

**审查边界：** 初始静态审查把 40 组嵌套别名列为候选，随后逐条核对了完整词条与子词条 ID，并在浏览器里遍历 26 门课程的最终渲染 DOM。40 组是复合关系对，不代表 40 处已确认错误。

### 已确认的根因

1. `dist/textbook-glossary.js:328` 的正则只在 ASCII 字母、数字和下划线两侧设置边界；汉字之间没有词边界，因此普通子词可以在更长中文术语内部命中。
2. 别名按长度降序排列，只能在同一个起始位置优先选择较长别名；如果完整术语从更早的中文前缀之后才开始、完整别名未收录，或术语被 HTML 行内标签切成多个文本节点，短别名仍可能先被标注。
3. `decorate()` 从 DOM 文本节点逐个匹配（`dist/textbook-glossary.js:364`）。节点之间无法匹配一个完整的连续术语；随后 `decorateHintTargets()` 又对控件的整体 `textContent` 选取第一个命中词（`:353`），两条路径需要统一审查。
4. 当前 `allowedAlias()`（`:342`）只有“变量”位于“协变量”内时的专门过滤，以及一条“激活”上下文过滤。该例外已覆盖上次的协变量问题，但词典中存在多组复合术语与普通子词的包含关系，逐项硬编码不利于全站维护。

### 当前已完成的局部修正

- 本地当前词典已注册“协变量”和“内部协变量偏移”，并在 `allowedAlias()` 中阻止“变量”作为独立词条覆盖“协变量”。相关词条位于 `dist/textbook-glossary.js:15`、`:99`，BatchNorm 互动说明中的实际用例位于 `dist/textbook-bias-playgrounds.js:141`。
- 用户提供的页面批注是 `?v=92`；此前发布的本地修正已进入 v93。该修正处理了已报告的协变量案例，但本次静态审查发现它仍是单个例外，不能据此认定全站所有复合词均已核对通过。

## 修正规约

- 只有经人工核对确有独立术语含义的词组才标为“原子复合术语”；相邻的普通修饰语不自动组成新的词典条目。
- 一个复合词的提示标题、解释和点击后词条必须指向完整术语。例：“协变量”显示“协变量（covariate）”；完整出现“内部协变量偏移”时显示该词条；单独出现“变量”仍显示变量词条。
- 词典为某个完整表面形式提供了词条时，完整词条优先；缺少相应词条时，不能凭空把“变量”等子词标成同义复合术语。确实只需解释其中一部分的语境可以保留，但不得让单个普通子词的高亮遮住有专门含义的整体词。
- 不对所有包含关系进行全局屏蔽。例如，多标签分类中的“分类”有时仍是读者需要的基础概念；是否优先整体词条，要由术语关系与该处教学意图决定。
- 正文标注、可聚焦的控件提示、代码行内提示和术语解释卡中的再标注使用同一匹配判定；代码块内容仍保持原样可复制。
- 不跨越段落、链接、按钮、代码块、KaTeX/数学公式、SVG 边界进行文本拼接；跨行内标签识别只在不改变现有结构、可访问性和复制行为时实施。
