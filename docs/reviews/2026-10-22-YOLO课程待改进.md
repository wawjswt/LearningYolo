## 3. 优先修正的表述边界

### P0-1：Anchor 的参考作用与解码范围需要同时解释

- [x] 修改“Anchor 不是对真实框的硬性限制”等容易被理解为任意扩张的表述。
- [x] 说明参考框不是最终预测框，但特定解码公式仍限定单个候选的表达范围。
- [x] 区分解码表达范围与训练时 Anchor 匹配门槛。

本课 Anchor-based Detect 的宽度公式为：

```tex
b_w = (2\sigma(t_w))^2 a_w
```

其中，`a_w` 为像素参考宽度，`t_w` 为模型输出的原始宽度参数，`σ` 为 Sigmoid。对有限实数输入，数学上有 `0 < b_w < 4a_w`；高度同理。有限精度实现可能数值饱和到边界。不能据此把单个 Anchor 的限制误写成整个模型只有同一个宽高上限。

### P0-2：“没有候选框”应明确是哪个阶段

- [x] 修正推理、排错课中“完全没有候选框”等含糊说法。
- [x] 区分原始输出形状异常、输出数值异常、置信度不足、阈值筛选后为空、NMS 后的最终结果。
- [x] 解释标准密集检测头的原始候选数量由输入形状和配置决定，图片没有目标也会产生原始预测。

### P0-3：明确代码片段的运行上下文

- [x] 为带 `self`、`features[i]` 等上下文变量的代码标注“源码片段”及所在类／方法。
- [x] 为改类别数和形状检查提供包含导入、模型构建、输入构造及输出说明的完整示例。
- [x] 区分模型构建时传入 `nc` 与构建完成后修改属性；后者不会自动重建输出卷积。

## 4. 教学结构与图解改进

当前情况：已有 `640→320→160→80→40→20` 和逐层尺寸表，但卷积公式仍是普通文本，`k、s、p、d、floor` 没有就近逐项解释。

- [x] 先用具体卷积演示输入、补边、卷积窗口移动和输出，再引入一般公式。
- [x] 用现有数学库排版尺寸公式，并解释每个符号。
- [x] 分别计算高和宽，说明矩形输入不能只追踪一个边长。
- [x] 解释通道数由输出滤波器数量决定，高宽由卷积几何参数决定。

- [x] 明确简单“除以 stride”的推导条件，不能把适用于整齐尺寸的例子推广到所有输入。

### P1-2：Neck——让 FPN/PAN 的连线可追踪

当前情况：两个小节主要靠正文和尺寸表表达融合过程，本课缺少逐步追踪的融合图。

- [x] 点击路径时同步高亮来源层、上采样／下采样、Concat 与后续 C3。
- [x] 每个融合点显示两路输入形状及输出形状。
- [x] 说明 Concat 为什么要求批次、高、宽一致，以及为什么只把通道相加。
- [x] 解释拼接保留两路信息，后续 C3 再学习融合；上采样不凭空恢复原始细节。
- [x] 提供两路高宽不一致的错误连线示例，指出应检查的上采样倍率或来源层。
- [x] 图中明确使用“Concat”节点，避免用加号误导为逐元素相加。

贯穿算例：

```text
深层特征 [1,512,20,20]
  → 上采样 ×2 → [1,512,40,40]
横向特征          [1,512,40,40]
  → Concat(dim=1) → [1,1024,40,40]
  → C3            → [1,512,40,40]
```

### P2-1：第二层——增加 P2 高分辨率检测分支

- [x] 基于官方固定版本 P2 配置，与标准三尺度配置逐项对照。
- [x] 解释 P2 的相对步长为 4，640×640 输入对应 160×160 网格。
- [x] 展示新增上采样、横向融合与返回较粗尺度的路径。
- [x] 核对新增后各层来源索引；官方示例 Detect 输入为 `[21,24,27,30]`，不能沿用标准结构的 `[17,20,23]`。
- [x] 核对 Detect 输入通道、尺度数量、stride、Anchor 初始化／适配和训练目标分配。
- [x] 说明损失中的尺度权重及训练缩放也应随实际实现检查；不能把三尺度数值机械复制到四尺度。
- [x] 核对预训练参数迁移、导出及后处理中的形状假设。
- [x] 讨论小目标收益的条件与计算、内存代价，不承诺增加 P2 一定提升指标。

固定每尺度 3 个 Anchor 时：

```text
三尺度候选数 = 3 × (80² + 40² + 20²) = 25,200
四尺度候选数 = 3 × (160² + 80² + 40² + 20²) = 102,000
```

候选数量的比例不能直接当作整网运行耗时或显存的比例。
